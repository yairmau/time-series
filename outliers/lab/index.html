Teaching notes & calculation choices
  1. Start with one spike: compare SD and MAD, then increase the spike height.
  2. Use the cluster: make the window shorter than the event, then much longer. Try a whole-record reference.
  3. Use the stuck sensor or challenge D: turn on repeated-value detection. Why can a plateau escape a statistical envelope?
  4. Try the genuine level shift: a flag does not establish that the data is wrong.
  5. Send flags to the gap stage, or use the temperature gaps. Predict before revealing the held-out original.

The challenge files have no supplied ground-truth labels. Only synthetic examples show known injected faults. Course excerpts retain their original spacing; the whole-record option uses that excerpt, not the full CSV.

SD uses n − 1. Quartiles use linear interpolation. MAD is computed around the median of each same window, then multiplied by 1.4826. Zero spread gives a collapsed envelope: any unequal value outside it is flagged. Equality with a limit is not flagged. A run rule uses the entire consecutive run and can use future readings, even with a trailing envelope.

The cubic option uses a natural cubic spline with zero second derivative at the first and last available observations. This differs from the default boundary conditions of the notebook’s interpolate(method='cubic'). It may overshoot. No method uses the held-out reference.

RMSE = square root of the average squared error, evaluated only where the input was missing and a finite estimate and reference are available. Check coverage before comparing methods. It cannot be measured for genuinely unknown values.
